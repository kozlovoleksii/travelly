## ✈️ Travelly — Registration Page
- A clean and modern registration page for the Travelly travel booking service.
- Designed to demonstrate form validation, responsive layout, and React Hook Form integration.

## ✨ Features
- Email and password validation with real-time error messages
- Password visibility toggle (show/hide icon)
- Dynamic checklist for password strength
- Checkbox confirmations (rules, age, promo consent)
- Fully responsive design for desktop, tablet, and mobile
- Custom background and promotional image section
- Beautiful modern UI with soft shadows and rounded corners

## 🛠 Tech Stack
- React + Vite
- TypeScript
- React Hook Form
- React Icons
- Plain CSS
- GitHub Pages for deployment
